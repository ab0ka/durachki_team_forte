# ml/scene — состояния сцены (A08)

Модуль считает по каждому сэмплу `clip.times` все 17 сигналов из `SIGNALS`: сейф, дверь, наличные, сумку, присутствие людей, движение, позу. Сигналы сглажены HMM из двух состояний. Главное правило: **«не обнаружили» ≠ «отсутствует»**. Значение, не подтверждённое наблюдением, помечается как неизвестное. В составные правила неизвестное не попадает ни как 0, ни как 1.

Модуль работает только на CPU и только локально. Нейросетей и весов у него нет: ему достаточно детекций A05, треков и зон A06, позы A07 и кадров A04. Обучаемый вариант необязателен (см. ниже).

## Публичный интерфейс

```python
from ml.scene import scene_states                     # сигнатура заморожена контрактом v1
states = scene_states(clip, dets, tracks, zones, pose_states)   # list[SceneStateEx], len == len(clip.times)

from ml.scene.core import scene_states_with_trace      # то же + trace (сырые признаки, ROI, предупреждения)
from ml.scene.types import SceneStateEx, signal_value, is_known
from ml.scene.io import dump_states, load_states       # JSON для кэша A03 / графиков
```

### `SceneStateEx`: совместимое расширение контракта без изменения файлов A01

`SceneStateEx` — подкласс `SceneState`, поэтому `isinstance(s, SceneState)` истинно, а `t` и `signals` работают как раньше. Новые поля:

| поле | смысл |
|---|---|
| `signals[name]` | лучшая оценка P(состояние=1). Без наблюдений плавно возвращается к априорной вероятности из `config.yaml` (низкой для «рисковых» сигналов), а не к 0.5 |
| `conf[name]` | 0..1, насколько значение подтверждено наблюдением, с затуханием `exp(−Δt/1 с)` |
| `known[name]` | `conf ≥ 0.5`. Значение можно использовать как факт «да» или «нет» |
| `visibility[name]` | 1 − окклюзия ROI людьми (для `safe_open`, `door_open`, `cash_visible`) |
| `provenance[name]` | источник: `det`, `roi`, `geom`, `traffic`, `track`, `pose`, `det_fallback`, `colour`, `learned`, `derived` или `none` (несколько — через «+») |
| `observed` | наблюдения вне `SIGNALS`: `unknown_person_in_cashier_area`, `workplace_empty(+_conf)`, `workplace_track_lost`, `safe_unattended` |
| `quality` | 0..1, качество кадра: резкость, экспозиция, контраст. Берётся из `clip.quality`, иначе считается сам |

Для правил A09 и A12 есть хелпер `signal_value(state, "safe_open")`: он возвращает `None`, если значение неизвестно. Для обычного `SceneState` без расширения возвращает значение как есть.

## Как считаются сигналы

| сигнал | «да» подтверждается | «нет» подтверждается | иначе — неизвестно |
|---|---|---|---|
| `safe_open` / `door_open` | детекцией `*_open`; сменой вида ROI, если удалось установить, какой из двух видов «открыт»; для двери — проходом человека через зону двери | детекцией `safe`/`door`; тем же видом ROI | вид не менялся и детекций нет; ROI перекрыт; кадр плохой |
| `cash_visible` | детекцией `cash` в зоне стола (desk/cash_tray, затем cashier_area); цвето-формовый классификатор купюр даёт только слабое свидетельство (conf ≤ 0.4) | стол виден **и** детектор работал **и** цветовой признак молчит | стол закрыт людьми, плохой кадр, нет детекций в видео |
| `cash_bag_visible` | детекцией `cash_bag`; зелёный блоб — слабо | только слабое «нет» (сумку легко не увидеть) | — |
| `cashier_present` | виден трек с ролью кассира | все «кассироподобные» треки подтверждённо ушли (см. ниже) | трек потерян |
| `cashier_in_workplace` | кассир в `cashier_area` (без неё — расширенный `desk`) | кассир виден вне рабочего места или его уход подтверждён | трек «растворился» посреди рабочего места; нет зоны; плохой кадр |
| `outsider_in_cashier_area` | в зоне человек с явной ролью `visitor` от A06 **или** с историей в `client_area` (пришёл со стороны клиента); инкассатор исключён | в зоне только сотрудники с явной ролью или никого | человек с неизвестной ролью: заполняется `observed.unknown_person_in_cashier_area`, outsider остаётся неизвестным |
| `collector_present` | роль `collector` или трек с сумкой рядом | все видимые люди — с известной ролью | — |
| `n_persons` | целое, медиана по 5 сэмплам; `conf` = качество × «детектор работал» | | |
| `workplace_unattended_with_cash` | трёхзначное И: наличные «да» (известно) ∧ рабочее место пусто (известно, уход подтверждён) не меньше `min_s` = 3 с. Помечается весь интервал с самого начала (офлайн) | наличных нет (известно) или рабочее место занято (известно) | любой операнд неизвестен → значение 0, `known=False` |
| `motion_energy` | `clip.quality` или межкадровая разность | | |
| `phone_*`, `eating_drinking`, `hands_hidden`, `cashier_facing_away`, `handover_motion` | из `pose_states` (A07); `conf` берётся из `pose_state.conf`, если есть | | без позы — слабый det-фолбэк ×0.7, `conf` ≤ 0.3 |

**Уход подтверждён**, только если трек исчез у края кадра или в зоне двери, либо был виден вне рабочего места. Трек, исчезнувший посреди рабочего места, означает «неизвестно», а не «ушёл». Трек, который «возник» посреди места, мог стоять там и раньше: 1.5 с до его появления тоже неизвестны. Режим «только детекции, без треков» уход подтвердить не может, поэтому в нём `unattended` не срабатывает.

### Сейф и дверь: начало видео не считается эталоном «закрыто»

1. **Эталон A** — маскированная медиана первых N чистых кадров: людей у ROI нет, качество кадра хорошее. Его состояние неизвестно, это просто «как было в начале».
2. **Изменение вида**: `d(t) = 1 − CS-SSIM(ROI_t, A)`. Кропы z-нормированы, а из SSIM убран яркостный член, поэтому общий сдвиг освещения и мягкие тени изменением не считаются. Люди маскируются; кадр с окклюзией больше `occlusion_max` в расчёт не идёт, и HMM держит прежнее состояние. Дрожание камеры компенсируется через phase correlation.
3. **Состояние B** — альтернативный вид, устойчивый не меньше 1 с и внутренне согласованный. Короткие или несогласованные изменения (проход человека, тень, шум) состоянием не считаются.
4. **Какое состояние «открыто»**, решают только абсолютные свидетельства:
   - детекции `safe_open`/`safe` в кадрах каждого состояния;
   - симметричный слабый априор формы: у открытого вида больше тёмного проёма относительно окружения и вертикальная кромка дверцы вне контура. Априор ограничен ±1.5 логита и работает только для сейфа.

   Если свидетельств нет, `label_conf = 0` и сигнал остаётся неизвестным. Сейф, открытый с первого кадра, поэтому не превращается в «закрытый эталон».
5. **Итог**: в логит-пространстве суммируются вид, прямые детекции и, для двери, проходы людей. Затем — HMM forward-backward: офлайн, переходы асимметричны и сходятся к априорной вероятности.

ROI берётся из зон A06 (`safe`, `door`, `desk`, `cash_tray`, `cashier_area`, `client_area`). Если зоны нет — из медианного бокса уверенных детекций. Пиксельные координаты нигде не захардкожены.

## Запуск

```bash
pip install -r ml/scene/requirements.txt
python -m pytest ml/scene -m "not gpu and not slow" -q        # 35 тестов, синтетика, без GPU и весов

# графики сигналов (сплошная линия — подтверждено, пунктир — неизвестно, красная — GT-секунда)
python -m ml.scene.plot --cache cache/<sha> --out signals.png --gt 22
python -m ml.scene.plot --video data/X-1.mov --out signals.png --gt 22   # посчитать на лету

# необязательное дообучение по ПРОВЕРЕННЫМ меткам
python -m ml.scene.train_signals --labels data/scene_labels.csv --videos data/videos \
    --out weights/scene/scene_signals.json [--model lr|mlp] [--zones-json data/scene_zones.json]
```

### Формат `data/scene_labels.csv`

```
video,signal,t_start,t_end,value,verified
X-1.mov,safe_open,0,12.5,0,1
Х-3.mov,safe_open,12.5,30,1,1     # кириллическая «Х» нормализуется: x-3
X-7,cash_visible,4.2,,1,1         # пустой t_end — точечная метка (ближайший сэмпл)
```

- `signal` — одно из `safe_open`, `door_open`, `cash_visible`; `value` — 0 или 1.
- `verified` — 1, true, yes или «да»: строку проверил человек. Непроверенные строки игнорируются; использовать их можно только с флагом `--allow-unverified`.
- Неразмеченные участки в обучение не попадают: неизвестное ≠ 0.

Обучение использует group k-fold по видео: одно видео целиком попадает в один фолд. В JSON сохраняются `cv.auc` и `reliability = 2·(AUC − 0.5)`. Модель смешивается с ручной фузией в логит-пространстве с весом `learned.weight` = 0.5. Модель не загружается, если `SENTINEL_MOCK=1` или файла нет. Формат — JSON без pickle, в git не коммитится (`weights/` в `.gitignore`).

## Конфиг и переменные окружения

- Все пороги лежат в `ml/scene/config.yaml`.
- `SENTINEL_SCENE_CONFIG=<yaml>` — переопределение поверх (глубокое слияние).
- `SENTINEL_SCENE_MODEL=<json>` — путь к обученной модели (по умолчанию `weights/scene/scene_signals.json`).
- `SENTINEL_MOCK=1` — обученная модель не грузится. Остальное работает как обычно: модуль лёгкий.

## Ограничения (честно)

- Пороги откалиброваны только на синтетике. На реальных роликах их нужно настроить по графикам `plot` (`roi_center`, `roi_scale`, `min_state_s`, `occlusion_max`, `unattended.min_s`).
- Без детекций A05 (`safe`/`safe_open`) сейф, который не менял вид за всё видео, остаётся неизвестным. Это сделано намеренно.
- Для двери априор формы выключен: у стеклянной двери нет надёжного направления «открыто или закрыто». Без детекций `door_open`/`door` и без проходов людей дверь остаётся неизвестной.
- Цвето-формовый классификатор купюр сам по себе не даёт `known`, потому что белые документы и упаковки похожи на купюры.
- Роли людей определяются по поведению, зонам и сумке; лица не используются. Без зон `cashier_area`/`client_area` посторонний не подтверждается.
- Сильная перспектива при другом ракурсе: членство человека в зоне считается по точке на 0.6 высоты бокса (`anchor_y`). Для наклонной камеры, возможно, лучше 0.8–0.9.

## Для интегратора

1. **Ветка и история.** Ветка основана на первой версии коммита A01 (`076a23b`, ещё до переписывания его истории) и не имеет общей истории с `main`. По указанию владельца историю не переписывал и `main` не мерджил. Переносить нужно только `ml/__init__.py` (пустой) и `ml/scene/**`. `contracts/*` и `.gitignore` в ветке — старая копия A01, её не брать. `_contract_fallback.py` удалить после мерджа A01; `_contract.py` сам переключится на `contracts.sentinel_contracts`.
2. **A03 pipeline.** Вызов: `ml.scene.scene_states(clip, dets, tracks, zones, pose_states)`. Для графиков в кэш сохранять `ml.scene.io.dump_states(states, cache/<sha>/scene_states.json, trace=trace, meta={"gt_sec": ...})` (trace — из `scene_states_with_trace`). Бюджет времени: модуль сам увеличивает шаг, если сэмплов больше `roi.max_frames` = 800.
3. **A09 rules / A12 fusion.** Читать `signal_value(state, name)` или `state.known[name]`, а не голое `signals[name]`.
   - Не подставлять неизвестное как 0. Особенно для `cashier_in_workplace`: «нет детекции» ≠ «ушёл».
   - Для V01 брать `outsider_in_cashier_area`, только если `known`. `observed.unknown_person_in_cashier_area` — кандидат на проверку VLM (A11), а не нарушение.
   - Для V03 есть `observed.safe_unattended`: открытый сейф при подтверждённо пустом рабочем месте.
4. **A04 ingest.** `clip.quality` распознаётся в любом из форматов:
   - `list[float]` (качество по сэмплам);
   - `list[dict]` с ключами `quality`/`score` и `motion_energy`/`motion`;
   - `dict` со списками под теми же ключами.

   Иначе модуль считает качество сам.
5. **A06 track.** Нужны зоны `cashier_area`, `desk`, `safe`, `door`, `client_area` (опционально `cash_tray`) и роли с `role_conf`. Без ролей работают эвристики: время в зоне, сумка, история в `client_area`. Роль `visitor` с `role_conf ≥ 0.4` подтверждает постороннего.
6. **A07 pose.** Если `pose_signals` вернёт `SceneState` с полем `conf: dict` (например, тот же `SceneStateEx`), уверенность учтётся. Иначе позе доверяем с `conf = 1`.
7. **Предложение A01 (контракт v1.1, аддитивно).** Внести поля `conf`, `known`, `visibility`, `provenance`, `observed`, `quality` в общий `contracts/extensions.py` как `SceneStateEx`, чтобы и другие модули (A07) отдавали уверенность одинаково. Пока класс живёт в `ml/scene/types.py`.

### Принятые решения (автономно)

- Неизвестное в `signals` — это posterior HMM, который сходится к априорной вероятности. Это консервативно для потребителей, не читающих `known`: априорная вероятность рисковых сигналов низкая.
- `outsider_in_cashier_area` исключает инкассаторов: их присутствие — отдельный сигнал `collector_present`.
- `workplace_unattended_with_cash` по умолчанию не включает открытый сейф (`unattended.include_open_safe: false`), чтобы не путать V02 и V03. Открытый сейф идёт отдельно в `observed.safe_unattended`.
- Обучаемый вариант смешивается с ручной фузией (вес 0.5), а не заменяет её: меток мало.
