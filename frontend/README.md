# frontend/ — веб-интерфейс Kassa Sentinel (A15)

Vite 6 + React 18 + TypeScript 5.9 + Tailwind 3.4. Русский язык, светлая/тёмная тема, адаптив от 375 px.
Шрифты (Inter, Manrope — @fontsource-variable, OFL-1.1) и иконки (lucide-react, ISC) — в бандле, **никаких CDN**.
ML-моделей фронтенд не содержит (`models.json` = `[]`).

## Запуск

```bash
cd frontend
npm ci                    # один раз, с интернетом (дальше офлайн)
npm run build             # → frontend/dist (A02 раздаёт его на "/")
npm test                  # vitest: утилиты, разбор ответа, вердикт, демо
npm run dev               # dev-сервер :5173, прокси /api и /ui → VITE_PROXY_TARGET (по умолчанию http://127.0.0.1:8000)
```

Демо без бэкенда: `http://localhost:5173/?demo=1` — **синтетическое демо** с постоянной пометкой
«СИНТЕТИЧЕСКОЕ ДЕМО»; реальные файлы в демо не загружаются и не анализируются.

## Путь пользователя

1. **Вход** — ключ доступа → `POST /ui/v1/session` → сервер ставит HttpOnly cookie. Ключ не сохраняется
   (ни localStorage, ни URL, ни бандл) — живёт только в памяти вкладки.
2. **Загрузка** — drag&drop, проверка .mov/.mp4 и размера, реальный прогресс XHR `upload.onprogress`.
3. **Обработка** — поллинг `GET /ui/v1/jobs/{id}` раз в 1,5 с; степпер по `stage`; процент и ETA — только если
   сервер присылает `progress` (иначе неопределённый индикатор, без выдуманных цифр).
4. **Результат** — баннер с формулировкой ТЗ; плеер (`/ui/v1/jobs/{id}/video`, cookie + Range) с тепловой полосой
   риска и маркерами эпизодов; карточки: тип, таймкод (клик → перемотка), уверенность, описание, кадры (лайтбокс, зум),
   нормы (документ, пункт, цитата, ссылка adilet, бейдж «цитата проверена»), «Как система пришла к выводу»,
   «Что система не проверяет»; экспорт JSON (схема ТЗ / полный отчёт), печать.
5. **Failed/неполный анализ никогда не показывается зелёным** «нарушений нет».
